Edit/delete icon buttons mirror `block_cell.html`'s pencil/trash SVG markup and `h-3 w-3` icon / `p-1` rounded-button sizing verbatim (no new icons invented, per this sprint's brief) but deliberately do NOT reuse that file's `bg-black/20`/`hover:bg-black/40`/`text-white` scrim verbatim: that treatment exists there specifically because a block cell's background is an arbitrary user-chosen hex color, so a translucent overlay is the only reliably-visible choice against literally any background (`ARCHITECTURE.md`'s "Hover-control icon buttons" note).
